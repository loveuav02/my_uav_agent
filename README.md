# my_uav_agent
# 大语言模型驱动的无人机智能体系统探索

## 项目简介


本项目旨在探索大语言模型（Large Language Model, LLM）在无人机自主系统中的应用。


随着大语言模型在自然语言理解、任务规划和智能决策方面的发展，将LLM与无人机系统结合，有望实现更加智能、通用的人机交互和自主任务执行能力。


本项目基于以下开源项目和平台开展研究：

- Microsoft AirSim 无人机仿真平台
- Microsoft PromptCraft-Robotics 虚拟环境
- maris205/airsim_agent 大模型无人机应用开发项目


长期研究目标：

> 探索 LLM + UAV + Embodied AI（具身智能）方向的智能无人机系统。
